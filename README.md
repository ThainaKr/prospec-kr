# PROSPEC KR

Aplicação operacional de prospecção jurídica, responsiva para celular e conectada ao banco protegido do Supabase.

## Acesso

O acesso é feito por link mágico enviado ao e-mail previamente convidado pela Administradora. Não existem usuários ou dados de demonstração.

## Módulos

- Fila de prospecção por lista e tipo de mensagem
- WhatsApp direto no telefone do contato
- Listas, contatos e Recuperação via Telegram
- Modelos de primeira mensagem e follow-up
- Agenda em Hoje, Dia, Semana e Mês
- Notificações e relatórios
- Cadastro de chips, usuários e convites

## Segurança

Os dados pessoais não ficam no código. A interface usa somente a chave pública do Supabase; autenticação, autorização e ações operacionais são validadas no servidor.
