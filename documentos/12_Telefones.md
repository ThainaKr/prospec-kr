# 12 - Telefones

## Objetivo

Gerenciar todos os números telefônicos cadastrados para cada contato.

## Responsabilidades

- Cadastro
- Validação
- Histórico
- Situação
- Recuperação

## Relacionamentos

Cada contato poderá possuir diversos telefones.

Cada telefone pertencerá a apenas um contato.

## Observações

Quando todos os telefones forem considerados indisponíveis, o contato será encaminhado automaticamente para Recuperação de Contatos.
