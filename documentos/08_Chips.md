# 08 - Chips

## Objetivo

Gerenciar todos os chips utilizados pelo sistema.

## Responsabilidades

- Cadastro
- Operadora
- Número
- Saúde
- Estatísticas
- Histórico
- Status

## Status

- Ativo
- Pausado
- Restrito
- Banido

## Integração

Cada chip possuirá uma Sessão de WhatsApp vinculada.

Caso o chip deixe de estar ativo, ele deixará automaticamente de participar da distribuição das mensagens.
