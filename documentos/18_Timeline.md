# 18 - Timeline

## Objetivo

Registrar todo o histórico operacional de cada contato.

## Eventos

- Cadastro
- Distribuição
- Primeira mensagem
- Áudios
- Follow-up
- Agendamento
- Reunião
- Alterações
- Recuperação
- Encerramento

## Relacionamentos

Cada timeline pertencerá a um único contato.

## Observações

Nenhum evento será removido da timeline.

Todo o histórico permanecerá disponível para auditoria.
