# 17 - Notificações

## Objetivo

Informar usuários sobre acontecimentos relevantes do sistema.

## Tipos

- Retornos
- Agenda
- Sistema
- Saúde dos Chips
- Distribuição
- Recuperação de Contatos

## Relacionamentos

As notificações poderão estar vinculadas a:

- Usuário
- Contato
- Chip
- Sessão
- Agenda

## Funcionalidades

- Marcar como lida
- Marcar todas como lidas
- Filtros
- Ordenação
- Histórico
